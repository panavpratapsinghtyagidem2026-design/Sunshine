Sunshine Design System

A well-lit room, not a waiting room

Live render of the token layer and core components — React + CSS custom properties, light mode, tuned for older adults living alone. This page imports the exact tokens.css and base.css files used by the components.

Color

Warm paper neutrals instead of cool grays (institutional feel avoided), a desaturated harbor blue for trust, sage for health/growth, and exactly one warm accent — marigold — for "this needs you now."

Typography

Fraunces (display serif, the gravity of print) for headings against Hanken Grotesk (open, large x-height humanist sans) for body — legible at the larger sizes this audience needs without starting to "shout." Base size is 19px.

Space

Derived from the 56px comfortable tap target rather than a generic 8px grid — spacing and touchable area always agree.

Buttons

56px minimum height by default. One primary per screen — never stack decisive actions.

Inputs

Labels are permanent and visible — never placeholder-only or floating. Errors are shown with text + icon + border, never color alone.

Cards & Badges

Cards read as "raised paper" — soft shadow, generous padding, one calm radius family. Badges show state, paired with a shape (dot) so meaning never depends on color alone.

Navigation

Bottom tab bar, max 5 labeled items (no icon-only entries), SOS always present in the same position — found without reading, under stress.

SOS Button Proposed addition

Arm → countdown → cancel, instead of a confirmation dialog — someone in real distress is never blocked by a modal, while an accidental tap gets a calm window to stand down. Marigold, not danger-red: SOS means "help is coming," not "you're about to break something." The slow breathing ring says "I am always here," not "hurry up."

Idle

Armed — sending in 4s, tap to cancel

Empty state

"Nothing here yet" must never read as "you're doing something wrong" or "no one is here for you" — both are real risks for an isolated audience.
